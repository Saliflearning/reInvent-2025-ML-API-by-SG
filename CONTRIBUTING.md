# Contributing

1. Create a focused branch and keep examples synthetic.
2. Add or update tests before changing request or classifier behavior.
3. Preserve the explicit heuristic/non-production framing.
4. Do not rename existing AWS resources without migration and rollback evidence.
5. Run every command in the README verification block.
6. Open a pull request and wait for required safety, Python, Terraform,
   dependency-review, and CodeQL checks.

Use private vulnerability reporting for security concerns.
